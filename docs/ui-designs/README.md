## How to Use This Guide

1. **When creating a new component**, consult the relevant pattern file(s)
2. **Do NOT invent new styles** — reuse these patterns consistently
3. **If a pattern is missing** for your use case, consult the user before creating
4. **All patterns must respect constraints** in [AGENTS.md](../AGENTS.md) (no neon, no excessive blur, no decorative grids)
